## Ownership vocabulary

- **Originated / set direction:** use only for the portfolio thesis, priorities, standards, or designs Jonathan initiated.
- **Designed:** use for workflows, experience, authority boundaries, architecture, or standards Jonathan personally designed.
- **Built / implemented:** use only when the specific personal implementation can be named.
- **Led / orchestrated:** use for delivery across contributors and stakeholders; name collaborators or teams where the public context permits.
- **Contributed:** use when implementation or decision-making was shared and individual scope is not yet documented.
- Avoid “I did everything,” “visionary,” or sole-author language for team outcomes.

## Maturity labels

Every product or capability must be labeled as one of:

- Production
- Deployed internal capability
- Pilot
- Prototype
- Public build
- Specification
- Roadmap

Do not use “shipped,” “production,” or adoption language without a corresponding status and proof location.
